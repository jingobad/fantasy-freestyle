# Fantasy Kayak Freestyle – Krakau 2026

Statische, mobilefreundliche Einzelspieler-Demo für GitHub Pages.

## GitHub Pages veröffentlichen

1. Auf github.com ein öffentliches Repository `fantasy-freestyle` erstellen.
2. `index.html` und `.nojekyll` in das Stammverzeichnis des Repositories hochladen (optional auch README.md).
3. Unter **Settings → Pages → Build and deployment** als Source **Deploy from a branch** wählen, Branch **main** und Ordner **/(root)** auswählen, **Save**.
4. Sobald GitHub Pages veröffentlicht hat: `https://DEIN-GITHUB-NAME.github.io/fantasy-freestyle/` öffnen.

Die Demo speichert Spielstände lokal im Browser (localStorage). Sie bietet noch keine gemeinsamen Accounts, Online-Liga oder Synchronisation zwischen Geräten. Die historischen Daten sind in `index.html` eingebettet; für die Demo ist kein API-Zugang erforderlich.
